## 🔧 Configuration Parameters Reference

### HTML2Canvas Settings

| Parameter | Value | Purpose |
|-----------|-------|---------|
| scale | 3 | Higher resolution (3x pixel density) |
| backgroundColor | null | Preserve original page colors |
| letterRendering | true | Better text quality |
| dpi | 300 | Print-quality resolution |
| windowWidth | 794 | A4 page width in pixels |
| windowHeight | dynamic | Full content height |
| useCORS | true | Allow external resources |
| allowTaint | true | Allow mixed content |
| logging | false | Suppress debug output |

### jsPDF Settings

| Parameter | Value | Purpose |
|-----------|-------|---------|
| unit | 'mm' | Metric measurements |
| format | 'a4' | A4 page size |
| orientation | 'portrait' | Vertical layout |
| compress | false | No color compression |

### Image Settings

| Parameter | Value | Purpose |
|-----------|-------|---------|
| type | 'png' | Lossless format |
| quality | 0.98 | Near-lossless (98% fidelity) |

## 📋 Testing Color Accuracy

### Visual Test Checklist

**Primary Colors**
- [ ] Deep Burgundy (#5c0f1e) looks rich and dark
- [ ] Light Burgundy (#8e1c31) is noticeably lighter
- [ ] Very Dark Burgundy (#37060f) is nearly black

**Gold Colors**
- [ ] Gold (#d4af37) is bright and warm
- [ ] Light Gold (#f3d573) is pale but warm
- [ ] Pale Gold (#faf3e0) is barely visible, very pale

**Text Colors**
- [ ] Navy (#351c1f) is dark and legible

**Accent Colors**
- [ ] Border (#e8dcd8) is subtle and light
- [ ] Off-white (#fdfaf6) is nearly white with warm tint

1. Fill in sample DDM data
2. Click "Generate PDF"
3. Open PDF in Adobe Reader

### Step 2: Verify Colors
- [ ] Header is burgundy (not pink or pale)
- [ ] Gold accents are bright (not dull)
- [ ] White cards are pure white
- [ ] Text is navy (not gray)
- [ ] All colors match this reference guide

2. Compare to monitor
3. Verify colors appear accurate
4. Note any ICC profile adjustments needed
